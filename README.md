# Network Threat Analytics Dashboard

Business Intelligence and predictive analytics dashboard for cyber threat detection using Python, Django, machine learning, and visualization tools.

## Features

* Real-time cyber threat prediction
* Role-based dashboards
* Interactive graphs and analytics
* KPI-based reporting
* Threat trend visualization
* Detection accuracy monitoring

## Tech Stack

Python, Django, Scikit-learn, Pandas, HTML/CSS, JavaScript, SQLite

## Business Impact

* Faster threat identification
* Improved security monitoring
* Data-driven analytics and reporting
